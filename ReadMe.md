# Hi, I'm Prathamesh

Computer Engineering student at KJSSE, Mumbai, doing Honors in Cybersecurity. I like building things that sit where software meets hardware, and I spend most of my free time making games.

## About Me

- **Game development:** I build games in Godot, mostly with multiplayer networking. I started with [Playaround-Multiplayer](https://github.com/PrathameshSJ/Playaround-Multiplayer) and a [first-person shooter](https://github.com/PrathameshSJ/fps_shooter), and my current game is *Further Forever* ([releases](https://github.com/PrathameshSJ/FurtherForever-Releases)).
- **Security and ML:** As part of my cybersecurity track I work on network security. One example is [anomaly classification on the IoT-23 traffic dataset](https://github.com/PrathameshSJ/IoT23-network-traffic-anomalies-classification).
- **Hardware and embedded:** I like getting old or limited devices to do more than they were built for. [jiophone-ground-station](https://github.com/PrathameshSJ/jiophone-ground-station) turns a KaiOS feature phone into a telemetry and remote-control node.
- **Automation:** I write bots and pipelines that handle repetitive work, like an [Android workflow bot](https://github.com/PrathameshSJ/android-automation-bot) for Termux or emulators and a [YouTube video generator](https://github.com/PrathameshSJ/youtube-video-automation) that goes from images and text to a narrated, subtitled upload.
- **Apps:** I also build practical tools, like an [attendance app](https://github.com/PrathameshSJ/attendance_app) for tutors in Kotlin.

**Open to collaborating on** multiplayer games, AI/ML, and full-stack projects.
**Ask me about** multiplayer networking or Godot.
